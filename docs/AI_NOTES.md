
## Ошибки и исправления
- Первоначальная проверка Python увидела Windows launcher, но запуск из песочницы не удался. Агент отдельно проверил реальный запуск вне песочницы: Python 3.11.9 доступен.
- Адрес JSON-манифеста Flutter вернул NoSuchKey. Агент перешёл к официальному Git-репозиторию Flutter вместо использования непроверенного зеркала.
- Первый тест узкого экрана обнаружил переполнение заголовка и навигации. Агент добавил адаптивные ограничения ширины; повторная проверка прошла.
- Dart LSP и pip freeze столкнулись с кириллицей в абсолютном пути. Для Flutter использован временный ASCII-путь через subst, для версий Python-зависимостей — pip list без Git-инспекции editable-пакета.
- Визуальная проверка формы обнаружила слабый контраст выбранного способа оплаты. Агент задал явные цвета выбранного сегмента в общем ThemeData. Семантическое дерево Flutter включено на время жизни экрана для доступности web-клиента без отдельного жеста активации.
- Пользователь заметил, что поля денег допускают текст, а общий интерфейс выглядит шаблонным. Агент исправил недостающую фильтрацию (числовая клавиатура сама не запрещает буквы), заменил строковый ввод дат календарём и отдельным временем. По запросу пользователя исследованы реальные продукты; источники и направление переработки записаны в DESIGN_REFERENCES.md. Позже пользователь выбрал B — «Лагуну»; перенос описан ниже.
